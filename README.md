## 1. 프로젝트 개요
* **프로젝트 설명**: 카페(폴리텍점) 키오스크에서 화면 터치로 시작해 음성 안내와 음성 인식으로 식사 방식(포장/매장)과 주문(메뉴·수량)을 인식하는 WPF 프로토타입
* **배포 URL**: 해당 없음 (운영 배포 제외)

## 2. 기술 스택
* **Frontend**: WPF (C# 14, .NET 10, net10.0-windows)
* **Backend**: WPF 앱 내장 로컬 웹서버 (포트 6703) + WebSocket
* **음성**: TTS - Azure SunHi로 미리 만든 WAV (주문 확인 멘트는 실행 중 Azure SunHi로 생성, 실패 시 Windows 내장 한국어 음성) / STT - 휴대폰 Chrome Web Speech API
* **Database**: JSON 파일
* **Infrastructure**: 해당 없음 (HTTPS 접속용 Cloudflare Quick Tunnel만 사용)

## 7. 실행 방법

### 7.1 준비 사항
* **PC**: Windows 10 이상 (키오스크 PC: Windows 10), 인터넷 연결
* **.NET SDK 10.0.401**
* **cloudflared**: PowerShell에서 `winget install --id Cloudflare.cloudflared` (설치 후 PowerShell 다시 열기)
* **Azure Speech 키**: Azure Portal에서 음성 서비스(Speech, Free F0) 리소스를 만들고 **키 및 엔드포인트**의 키 1·지역을 사용자 환경 변수로 등록 (키는 코드·파일에 쓰지 않음)
  ```powershell
  setx AZURE_SPEECH_KEY "키1"
  setx AZURE_SPEECH_REGION "koreacentral"
  ```
* **(선택) Windows 한국어 음성**: 설정 → 시간 및 언어 → 음성에서 한국어 음성 추가 (Azure 실패 시 확인 멘트 대체 음성)
* **휴대폰**: Android Chrome (Galaxy S26 Ultra에서 확인)

### 7.2 실행
```powershell
git clone https://github.com/nantang-3/EasyOrder.git
cd EasyOrder
dotnet build
dotnet run --project src/EasyOrder
```
* 키오스크 화면이 전체 화면으로 뜨고, 5~10초 뒤 QR 코드가 표시됩니다.
* **종료**: `Alt+F4` (cloudflared도 함께 종료됨)

### 7.3 사용
* **터치 주문**: QR 화면 터치 → 시작 화면 터치 → 포장/매장 선택 → 메뉴 카드 터치 → 옵션 선택 → 주문 목록에 담기 → 주문 완료
* **음성 주문**: 휴대폰 카메라로 QR 촬영 → Chrome에서 열기 → "음성주문활성화" → "대답하기"를 눌러 포장/매장 말하기 → "주문하기"를 눌러 메뉴·수량 말하기 ("취소", "주문완료"도 가능) → 버튼을 한 번 더 누르면 녹음 종료

### 7.4 안내 음성 다시 만들기
```powershell
dotnet run --project tools/WavGenerator -- --only greeting.wav
```
* 파일: greeting.wav, ask-order.wav, retry.wav, touch-guide.wav, cancel.wav (`--only` 없이 실행하면 5종 모두 다시 생성)

### 7.5 문제 해결
* **"EasyOrder가 이미 실행 중입니다"**: 실행 중인 키오스크 창을 `Alt+F4`로 닫은 뒤 다시 실행
* **"내장 웹서버를 시작하지 못했습니다"**: 다른 프로그램이 포트 6703을 사용 중. `Get-Process EasyOrder, cloudflared | Stop-Process -Force` 후 다시 실행
* **QR 자리에 "cloudflared를 찾을 수 없습니다"**: cloudflared 설치 후 PowerShell을 다시 열고 실행
* **음성 인식 내용 확인(디버깅)**: 실행 폴더 `src/EasyOrder/bin/Debug/net10.0-windows/logs/recognized-YYYYMMDD.log`에 세션별 인식 텍스트가 기록됨
* **휴대폰에서 QR 주소가 "사이트에 연결할 수 없음(DNS_PROBE_FINISHED_NXDOMAIN)"**: 새 터널 주소를 너무 빨리 조회해 통신사 DNS가 "없는 주소"를 기억한 경우. 휴대폰 설정 → 연결 → 기타 연결 설정 → 프라이빗 DNS → 호스트 이름 `one.one.one.one`으로 바꾸거나 와이파이에 연결한 뒤, QR 표시 후 1분쯤 기다렸다가 다시 접속
* **휴대폰에서 소리가 안 남**: "음성주문활성화"를 눌렀는지, 휴대폰 미디어 볼륨·블루투스 연결 확인

### 7.6 키오스크 PC에서 실행 (배포)
키오스크 PC에는 .NET SDK와 소스 코드가 필요 없도록, 개발 PC에서 실행 파일 폴더를 만들어 복사한다.

1. **개발 PC**에서 배포 폴더 만들기 (저장소 밖 `EasyOrder-publish` 폴더에 생성)
   ```powershell
   dotnet publish src/EasyOrder/EasyOrder.csproj -c Release -r win-x64 --self-contained true -o ..\EasyOrder-publish
   ```
2. `EasyOrder-publish` 폴더를 통째로 키오스크 PC에 복사 (USB 등)
3. **키오스크 PC** 준비: cloudflared 설치, Azure 환경 변수 등록(7.1과 동일), (선택) 한국어 음성 추가
4. 키오스크 PC에서 `EasyOrder-publish\EasyOrder.exe` 실행 (전체 화면으로 시작, 종료는 `Alt+F4`)
5. (선택) Windows 시작 시 자동 실행: `Win+R` → `shell:startup` 입력 → 열린 폴더에 `EasyOrder.exe` 바로 가기 넣기
